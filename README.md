# Nexo · redirecionamento do endereço antigo

Este repositório serve o endereço antigo **studioct3d.com.br** e só redireciona para **nexostud.com.br**,
mantendo o caminho. Assim os links de pedido já enviados (`/p/...`) e os links de confirmação de e-mail continuam abrindo.
O site de verdade (Nexo) fica no repositório SaaSstudioCT, publicado em nexostud.com.br.

O site antigo da Nexo Studio está guardado, completo, na branch `site-antigo-nexo-studio`.
